## Design System

- **Cream:** `#FBF8F3` (background, warm base)

### Typography
- **Headings:** SF Pro Display (system font) or Playfair Display (serif for warmth)
- **Body:** SF Pro Text or Georgia
- **Accents:** Caveat or similar handwritten font for annotations

### Components
- **Hero:** Full-width with diagonal split or warm gradient

- **Device Mockups:** iPhone with recipe app screenshots
- **Social Proof:** Review cards, App Store rating badge

## Technical Requirements

### Performance
- **Page Load:** <2 seconds on 3G
- **Lighthouse Score:** 90+ (Performance, Accessibility, Best Practices, SEO)
- **Image Optimization:** WebP with fallback, lazy loading
- **Code Splitting:** Route-based, load only necessary JS

### SEO
- **Meta Titles:** 50-60 characters
- **Meta Descriptions:** 150-160 characters
- **Open Graph:** All pages have OG images, title, description
- **Twitter Cards:** Large summary card for homepage
- **Structured Data:** Organization, SoftwareApplication schema
- **Sitemap:** XML sitemap submitted to Google Search Console

### Accessibility
- **WCAG 2.1 AA Compliant**
- **Keyboard Navigation:** All interactive elements accessible
- **Screen Reader:** Proper ARIA labels, semantic HTML
- **Color Contrast:** 4.5:1 minimum for body text, 3:1 for large text

### Mobile-First
- **Responsive:** Breakpoints at 640px, 768px, 1024px, 1280px
- **Touch Targets:** Minimum 44×44px
- **Viewport:** Proper meta viewport tag
- **Fast Tap:** No 300ms delay

## Content Management

### Tech Stack Recommendation

**Option A: Next.js + MDX (Recommended)**
- Fast, modern, great SEO
- MDX for content editing
- Deploy on Vercel or Netlify
- Easy integration with Rationale website

**Option B: Webflow**
- No-code, easy to update
- Great templates available
- Slightly slower, more expensive
- Good for non-technical updates

**Option C: WordPress**
- Familiar, lots of plugins
- Heavier, slower
- Requires more maintenance
- Not recommended for this use case
