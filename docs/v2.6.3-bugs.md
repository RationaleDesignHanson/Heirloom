### BUG-011: Demo user recipes accumulate without cleanup

| Field | Value |
|-------|-------|
| **Severity** | Medium |
| **Phase** | Infrastructure |
| **Device** | N/A (Server-side) |
| **Status** | Open |
| **Found** | 2026-02-22 |

**Description:**
When testing the share flow with demo users (demo_grandmazing, etc.), the demo users "modify" recipes and send them back. These modified recipes accumulate in the demo users' Firebase collections (`users/demo_*/recipes/`).

Over time with repeated testing, demo user collections will grow unbounded with orphaned test recipes.

**Expected behavior:**
- When a user sanitizes/deletes a recipe that came from a demo user's modification, the corresponding recipe in the demo user's Firebase collection should also be deleted
- OR: A scheduled cleanup job should periodically purge non-seeded recipes from demo users

**Files to consider:**
- `DemoSocialBehaviorService.swift` — demo share behavior
- Cloud Function or seed script for cleanup
- Could add `isDemoSeed: true` flag to seed recipes and delete anything without it

**Fix complexity:** Medium (needs server-side cleanup logic)

## Fixed Bugs

### BUG-007: Version dropdown/diff view not visible ✅ FIXED
**Root cause:** UUID case mismatch - queries used uppercase but Firebase docs stored lowercase
**Fix:** Changed all Firebase queries to use `firebaseString` (lowercase), migrated 33 existing lineage docs

### BUG-008: Family tree/lineage link not visible ✅ FIXED
**Root cause:** Same UUID case mismatch + RecipeLineageService required local lineage to exist
**Fix:** Made RecipeLineageService resilient - now checks Firebase directly if local lineage missing

### BUG-012: Offline mode hides version selector and Family Tree ✅ FIXED
**Root cause:** NWPathMonitor observation not triggering SwiftUI updates through @Environment; also condition mismatch between online/offline states
**Fix:**
- Added timer-based polling (0.5s) of NetworkMonitor.isConnected
- Fixed condition to show offline indicator when `versions.count > 1 OR heritageChain.count > 0`
- Now shows "X versions (offline)" dropdown and disabled Family Tree with "(offline)" label
- Note: Works instantly on real device; iOS Simulator has known NWPathMonitor limitations for WiFi reconnection

### BUG-013: "0 shares" text wrapping issue in lineage view ✅ FIXED
**Root cause:** Text without `.fixedSize()` wrapping mid-word
**Fix:** Added `.fixedSize()` to stat items in LineageTimelineView

### Additional fixes in this session:
- Demo recipes now include instructions on document (for diff view)
- Added "boxes", "jar", "bottle", etc. as recognized units
- Fixed invalid SF Symbols (`chart.tree` → `rectangle.3.group`)
