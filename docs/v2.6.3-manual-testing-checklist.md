## Apple Account Deletion Compliance

### Requirements (Effective June 30, 2022)

| Requirement | Our Implementation | Status |
|-------------|-------------------|--------|
| **In-app deletion option** | Settings → Privacy → Delete Account | ☐ |
| **Easy to find** | Prominent in Privacy settings | ☐ |
| **Delete entire account** (not just disable) | Full data deletion | ☐ |
| **Delete all personal data** | Recipes, collections, connections, profile, notifications, shares | ☐ |
| **Sign in with Apple: Revoke tokens** | Must call REST API to revoke | ☐ |
| **Handle active subscriptions** | Notify user to cancel first | ☐ |
| **Inform user of timeline** | Show deletion progress | ☐ |
| **Confirm when complete** | Toast/alert on completion | ☐ |

### Sign in with Apple - Token Revocation

| # | Test | Steps | Expected | Status |
|---|------|-------|----------|--------|
| A.1 | Apple re-auth prompt | 1. Sign in with Apple account<br>2. Delete account | "Sign in with Apple" prompt appears | ☐ |

### Data That Must Be Deleted

- ✅ User profile (`users/{userId}`)
- ✅ Recipes (`users/{userId}/recipes`)
- ✅ Collections (`users/{userId}/collections`)
- ✅ Connections (`users/{userId}/connections`)
- ✅ Notifications (`users/{userId}/notifications`)
- ✅ Shares created by user (`shares` where `ownerId == userId`)
- ✅ Firebase Auth account
- ✅ Apple Sign-In token (revoked via REST API)
