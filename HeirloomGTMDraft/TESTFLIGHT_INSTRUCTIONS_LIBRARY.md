## Segment-Specific Variants

### Power User Variant (All Phases)

**Characteristics:**
- Recipe enthusiasts
- Will add 50+ recipes
- Want advanced features

**Instruction Style:**
- Give them challenges
- Ask for detailed feedback
- Test edge cases and scaling
- Reward with early access

**Example (Week 2):**
```
POWER USER CHALLENGE:

This week: Add 50 recipes and stress-test collections.

BONUS CHALLENGES:
🏆 Add a recipe with 20+ ingredients
🏆 Create a collection with 100+ recipes
🏆 Find a website our AI can't handle
🏆 Use every feature at least once

REWARD:
Top 3 testers get:
• Shoutout in launch announcement
• Beta access to all future products
• Free merch (Heirloom stickers!)

Leaderboard: [link]
```

---

### Casual User Variant (All Phases)

**Characteristics:**
- Cooks occasionally
- Will add 5-10 recipes
- Wants simplicity

**Instruction Style:**
- Keep it simple
- Focus on real-world use
- No jargon
- Emphasize ease

**Example (Week 2):**
```
WEEK 2: JUST COOK SOMETHING

Last week you added some recipes. This week, actually cook one!

SIMPLE TASK:
□ Pick a recipe you saved
□ Cook it (or at least try to)
□ Tell us: Was the recipe easy to follow?

Quick survey: [link] (2 min)

That's it. No tech stuff, just cooking.

If anything was confusing or broken, shake your phone and tell us!

Happy cooking 🍳
Matt
```

---

### Technical User Variant (All Phases)

**Characteristics:**
- iOS developers/designers
- Will notice polish issues
- Care about performance

**Instruction Style:**
- Technical language OK
- Focus on performance, bugs
- Ask for architecture feedback
- Geek out together

**Example (Week 2):**
```
DEV BUILD NOTES:

Week 2 focus: Performance & edge cases

WHAT WE CHANGED:
• Migrated to async/await for API calls
• Added pagination (100 recipes/page)
• Implemented lazy loading for images
• Reduced memory footprint by 40%

WHAT TO TEST:
□ Load time with 100+ recipes
□ Memory usage on older devices (iPhone 12)
□ Any UI jank or dropped frames?
□ Accessibility issues (VoiceOver, Dynamic Type)

TECH STACK (if you're curious):
• SwiftUI + Combine
• CloudKit for sync
• OpenAI API for extraction
• No SPM dependencies (all native)

Feedback: beta@heirloom.app
Include device model + iOS version

Geek out with us 🤓
```
