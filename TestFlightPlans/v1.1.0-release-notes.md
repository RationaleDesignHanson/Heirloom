# Heirloom v1.1.0 - TestFlight Release Notes

## What's New: AI Features Work Instantly!

**No Setup Required** - AI-powered recipe features now work out of the box with 100 free imports per day.

### New Features

**Instant AI Cookbook Scanner**
- Snap a photo of any cookbook recipe
- AI automatically extracts ingredients, steps, and details
- No API key setup needed - works immediately
- OCR + AI structuring for accurate results

**Smart Ingredient Parsing**
- AI understands complex formats (fractions, ranges, mixed units)
- Handles "1-2 cups flour" or "2 tbsp (1/4 stick) butter" perfectly
- Automatic fallback to regex if offline

**Bulk URL Import**
- Import 3-5 recipe URLs at once
- All processed in parallel for speed
- Works with 500+ recipe sites

**Transparent AI Settings**
- See "Shared Key" badge in Settings → AI Features
- Real-time quota tracking: "X/100 recipes today"
- Optional: Add your own Anthropic key for unlimited usage
- Monitor token usage and costs

### What to Test

**Instant AI (Zero Setup)**
1. Launch app for the first time
2. Import a recipe URL or scan a cookbook
3. AI features work immediately - no configuration!
4. Check Settings → AI Features to see quota

**Daily Quota & Limits**
- Import multiple recipes throughout testing
- Watch quota count down in Settings
- At 100/day limit, verify friendly error message
- Counter resets at midnight local time

**Personal Key Upgrade (Optional)**
- Tap "Add Your Own Key (Unlimited)" in Settings
- Add Anthropic API key (free $5 credit at console.anthropic.com)
- Badge changes to "Personal Key"
- Quota disappears (unlimited usage)
- Can remove key anytime to return to shared

**Cookbook Scanner Accuracy**
Test with various sources:
- Modern printed cookbooks
- Vintage cookbooks (1950s-1980s)
- Magazine recipe pages
- Printed web recipes

**Bulk Import Performance**
- Paste 3-5 recipe URLs (one per line)
- Verify all import correctly in parallel
- Check quota decrements properly

**Offline/Error Handling**
- Enable Airplane Mode
- Try importing recipe
- Verify graceful fallback with clear error
- Re-enable network and retry

### Known Issues

- Handwritten recipes may have reduced OCR accuracy
- First AI request may take 2-3 seconds (subsequent faster)
- Non-English recipes have reduced parsing accuracy

### Privacy & Security

- Shared API key is for convenience only
- Your recipes are NEVER used for AI training (Anthropic policy)
- Personal API keys stored securely in iOS Keychain
- All data encrypted in transit (HTTPS)
- No third-party data sharing

### Technical Details

- **AI Provider:** Anthropic Claude (Haiku 3 fast tasks, Sonnet 3.5 complex)
- **OCR:** iOS Vision framework (on-device)
- **Rate Limiting:** 100 requests/day (shared key), unlimited (personal key)
- **Cost:** ~$0.0004 per recipe import (covered by shared key)
- **Reset:** Daily at midnight local time
