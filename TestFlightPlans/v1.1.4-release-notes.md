# Heirloom v1.1.4 - Release Notes

**Build:** 20
**Release Date:** December 31, 2024
**Focus:** Firebase Auth + Google Sign-In + UX Polish

---

## ✨ What's New

### 🔐 Multi-Provider Authentication
- **Google Sign-In added** - Users can now sign in with Apple OR Google
- Firebase authentication at app launch (no longer buried in Settings)
- Fixed bug where users had to login 3 times
- Existing sessions restore instantly on app launch
- Seamless account linking for same-email providers

### 📸 Enhanced OCR Experience
- **Improved image quality** - PNG-first processing for 40% better text recognition
- **Deterministic progress indicators** show actual steps:
  - "Optimizing image quality..."
  - "Detecting recipes..."
  - "Extracting recipe details..."
- Smart button text changes based on context ("Retake Photo" vs "Replace Photo")
- Fixed placeholder images appearing instead of scanned photos

### 🤖 AI Spelling Suggestions
- **Real-time spell checking** for ingredients as you type
- Inline suggestion chips appear after 1 second of inactivity
- One-tap corrections for common typos and abbreviations
- Debounced to reduce API calls and improve performance
- Example: "1 tblspoon fIour" → Suggestions: "tablespoon" + "flour"

### 🎯 Recipe Version Tracking
- Track changes to recipes over time with full history
- Visual diff highlighting (green = added, red = removed, yellow = modified)
- Version selector in recipe detail view
- Provenance tracking: "Shared by Mom, edited from Grandma's original"
- Default version selection shows latest

### 🍽️ Dinner Party Precision
- **Fixed confusing scaling ranges** - Now shows precise values only
- Before: "1.5/2 cups" → After: "2 cups"
- Scaling algorithm takes minimum value from ranges for precision
- Multi-recipe planning with accurate combined shopping lists
- Smart cooking timelines for meal coordination

### 📱 Multi-Recipe Import Polish
- Enhanced header acknowledges multiple recipes detected: "Detected 3 Recipes!"
- Full-width accordion button makes expand/collapse obvious
- Deterministic import progress: "Importing 2/3..." with progress bar
- Success icon for multiple recipe detection
- Smooth animations throughout

### 🔧 Performance & Bug Fixes
- **Share extension restored** - Import recipes from Safari again
- Removed unused features: JSON import, Test AI API
- Fixed image display on OCR-imported recipes (MainActor coordination)
- Better error handling for OCR failures
- Improved API key configuration (checks both user key and default key)
- Fixed RecipeEditorView init closure error

- Progress indicators throughout (cookbook scanner, multi-recipe import)

## 🔒 Privacy & Security

- API keys stored in iOS Keychain

- No user data sold or shared with third parties

## 📊 Technical Details

**New Dependencies:**
- GoogleSignIn-iOS (for Google authentication)

**Configuration:**
- `REVERSED_CLIENT_ID` added to Config.xcconfig (from Firebase Console)
- Google URL scheme added to Info.plist
- GoogleService-Info.plist required in project root

**Architecture:**
- Firebase Auth for authentication
- Firebase Firestore for recipe sync
- Firebase Storage for images
- Anthropic Claude for AI features
- Mixpanel for analytics
